# Conmine

[**Baixar instalador para Windows**](https://github.com/YukiiSZ/Conmine-downloads/releases/download/launcher-v0.2.0/Conmine-Setup.exe)

Minecraft Java **1.21.1 + NeoForge**, com o pacote Cobblemon do Conmine.

O instalador permite escolher a pasta. Ao clicar em Jogar, o launcher prepara o jogo e verifica os mods publicados. Os downloads não exigem conta GitHub.

O login por nome local está disponível. As integrações Google e Microsoft aguardam a configuração dos aplicativos do Conmine e não simulam autenticação.

## Arquivos públicos

Use os anexos das Releases para baixar o instalador, o launcher portátil e os mods completos. A Release marcada como **Latest** corresponde ao manifesto do pacote de mods, utilizado pelo atualizador automático.

O código original do launcher permanece em repositório privado. Este repositório contém somente arquivos de distribuição, metadados, licenças e a automação mínima de publicação.

Os arquivos originais do Minecraft são baixados diretamente da Mojang. Mods mantêm suas licenças; consulte `THIRD_PARTY_MODS.txt` nos anexos do pacote. Projeto independente, não afiliado à Mojang ou à Microsoft.
